## Опис лабораторної роботи
Ця робота присвячена аналізу часових рядів індексів вегетації (VCI, TCI, VHI) для областей України. Робота розділена на дві логічні частини, кожна з яких оформлена у вигляді окремого інтерактивного ноутбука:
1. `lab2_1.ipynb` — Модуль первинного парсингу, чистки та фільтрації аномалій у даних Pandas DataFrame.
2. `lab2_2.ipynb` — Обчислення статистичних екстремумів, аналіз посух та побудова регресійних моделей за допомогою SciPy.
