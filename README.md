## Опис архітектури проєкту

Проєкт реалізовано відповідно до принципів модульного об'єктно-орієнтованого програмування. Кожен логічний компонент системи повністю ізольований у власних файлах конфігурації (`.hpp` та `.cpp`):

1. **`CameraProvider`** — відповідає за низькорівневе підключення до апаратного забезпечення, ініціалізацію відеопотоку (`cv::VideoCapture`) та потокову передачу матриць кадрів.
2. **`KeyProcessor`** — потоковий обробник подій клавіатури. Містить безпечний перелік режимів `enum class Mode` та виконує тригер перемикання фільтрів.
3. **`FrameProcessor`** — обчислювальний модуль додатка. Здійснює математичні трансформації над матрицями зображень (колірні простори, згладжування, лінійні зсуви), веде облік метрик FPS, розраховує середню інтенсивність каналів та координує інтерактивне малювання геометричних примітивів.
4. **`Display`** — модуль виводу графічної інформації (`cv::imshow`). Відповідає за створення віконного інтерфейсу, реєстрацію зворотних викликів (callbacks) для повзунків та маніпулятора миші.
5. **`main()`** — вхідна точка програми, яка зв'язує всі модулі в єдиний синхронний конвеєр обробки всередині головного циклу `while(true)`.

## Доступний функціонал та режими роботи

### Перемикання режимів фільтрації (Клавіатура):
* `0` — **Normal Mode:** Базовий кольоровий відеопотік з камери.
* `1` — **Inversion Mode:** Побітова інверсія кольорових каналів матриці (`cv::bitwise_not`).
* `2` — **Gaussian Blur:** Високочастотна фільтрація розмиттям Гаусса з фіксованим ядром $15 \times 15$.
* `3` — **Canny Edge:** Детектор виділення меж контурів об'єктів із попередньою конвертацією в градації сірого.
* `4` — **Glitch Effect:** Художній ефект зміщення хроматичних каналів зображення (колірні канали $R$ та $B$ штучно розсуваються в протилежні боки по горизонталі).

### Інтерактивні елементи та OSD:
* **Слайдер «Яскравість»:** Динамічно змінює коефіцієнт зміщення яскравості пікселів у діапазоні від $-50$ до $+50$ за допомогою лінійної конвертації.
* **Інтерактивна миша:** Утримування та перетягування ЛКМ (лівої кнопки миші) дозволяє малювати зелений прямокутник поверх відеопотоку в реальному часі.
* **Екранна телеметрія (On-Screen Display):** У лівому верхньому кутку кадру виводиться живий лічильник **FPS** та поточні усереднені характеристики інтенсивності пікселів по кожному з каналів **Mean BGR**.

## Вимоги до операційної системи та заліза

* **Операційна система:** Linux (тестовано на чистій Ubuntu 22.04 / 24.04 LTS), Debian.
* **Архітектура процесора:** x86_64 або ARM (з підтримкою інструкцій прискорення).
* **Компілятор:** GCC / G++ версії 11.0 або новішої з підтримкою стандарту **C++17**.
* **Система збирання:** CMake версії 3.10 або новішої.
* **Апаратні вимоги:** Обов'язкова наявність підключеної та працездатної веб-камери (індекс пристрою `/dev/video0`). У разі запуску на віртуальних машинах (VirtualBox/VMware), пристрій камери має бути примусово прокинутий (Pass-through) в гостьову ОС.
