##  Опис завдання
Головна мета роботи — дослідити можливості візуалізації багатовимірних масивів даних (Multivariate Data), провести попереднє очищення даних (Data Cleaning) та побудувати комплексні графіки для виявлення прихованих залежностей, трендів та кореляцій між атрибутами.

### Основні етапи виконання:
* **Вибір датасету:** Обрано багатовимірний датасет `Cars93_miss`, який містить пропущені значення (Missing Values) та три типи атрибутів: категоріальні (Categorical), цілі числа (Integer) та дійсні числа (Real).
* **Data Cleaning (Очищення):**
  * Пропуски у стовпцях `Price` та `Horsepower` заповнено середнім значенням стовпця (`mean`).
  * Пропуски у стовпці `MPG.city` заповнено медіанним значенням (`median`).
  * Рядки з критичними пропусками в категоріальних ознаках (`Manufacturer`, `Type`, `Cylinders`) повністю видалено.
* **Побудова графіків (Візуалізація):** Створено 6 взаємопов'язаних графіків:
  * **Scatter Plot:** Залежність ціни від потужності двигуна з додатковим групуванням за типом кузова (візуалізація 3D даних).
  * **Гістограма:** Розподіл цін, розбитий чітко на 5 заданих діапазонів (`bins=5`).
  * **Line Plot:** Тренд зміни ціни залежно від об'єму паливного бака.
  * **Box Plot:** Аналіз варіативності та розподілу цін для різних типів кузова.
  * **Bar Plot:** Порівняння середньої потужності автомобілів виробництва США та інших країн.
  * **Heatmap:** Матриця лінійної кореляції між усіма числовими атрибутами датасету.
