## Опис завдання

Основна мета роботи — розробить інтерактивний вебдодаток для кінцевих користувачів, який дозволяє проводить первинний візуальний аналіз часових рядів супутникових індексів вегетації (VCI, TCI, VHI) України без знання мови програмування Python чи запуску сирих скриптів.

### Специфікація реалізованого функціоналу:
1. **Інтерактивна панель керування:** Додаток містить дворівневу систему фільтрації:
   * Випадний список (`st.selectbox`) для вибору типу індексу та текстової назви області (сортування за українською абеткою).
   * Інтерактивні слайдери (`st.slider`) для обмеження діапазону тижнів та років аналізу.
2. **Керування станом (Логіка Reset):** Реалізовано повне відновлення стартових значень фільтрів за допомогою зв'язку віджетів із внутрішнім сховищем стану додатка `st.session_state`.
3. **Обробка колізій сортування:** Чекбокси сортування за зростанням/спаданням значень вибраного індексу запрограмовані через механізм зворотного виклику (`on_change`). Ввімкнення одного автоматично деактивує інший, запобігаючи логічному збою фільтрації.
4. **Вкладки для відображення результатів:**
   * ** Таблиця даних:** Показує відфільтрований DataFrame з автоматичним підрахунком кількості знайдених записів.
   * ** Часовий ряд області:** Будує хронологічний лінійний графік динаміки обраного індексу для конкретної області з коректно розміченою, неперевантаженою віссю часу.
   * ** Порівняння областей:** Наочний графік порівняння обраної області (виділена товстою червоною лінією) на фоні напівпрозорих сірих ліній середньорічних значень усіх інших областей України.
5. **Двоколонкова структура сайту:** Відповідно до вимог ТЗ, усі елементи керування розміщено в лівій колонці сторінки, а результати, графіки та таблиця — у правій.
