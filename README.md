##  Опис завдання
Лабораторна робота присвячена первинному аналізу, очищенню та статистичній обробці структурованих даних за допомогою інструментарію бібліотеки Pandas.

### Частина 1: Аналіз VHI індексів областей
* **Мета:** Очищення та аналіз супутникових даних індексів вегетації (VHI) для адміністративних одиниць України.
* **Функціонал:**
  * Читання та об'єднання великої кількості CSV-файлів за допомогою `pd.read_csv` з гнучким обробленням зміщених заголовків та пошкоджених рядків (`on_bad_lines='skip'`).
  * Реалізація процедури пошуку екстремумів (Min, Max) VHI для заданої області за конкретний рік.
  * Пошук років із критичними посухами (VHI < порогу).
  * Фільтрація датасету за умовою помірної посухи (VHI в межах від 20 до 35).

### Частина 2: Статистичний аналіз та регресія
* **Мета:** Розрахунок відсоткових частот посух та моделювання довгострокових кліматичних трендів.
* **Функціонал:**
  * Обчислення відсотка площі (часу), що постраждала від сильних посух.
  * Побудова лінійної регресії залежності індексу VHI від часу за допомогою математичного апарату `scipy.stats.linregress` для оцінки кліматичних змін.
