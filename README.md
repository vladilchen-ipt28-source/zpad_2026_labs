## Опис завдання

Головна мета роботи — реалізувати інтерактивний програмний комплекс для моделювання гармонічних сигналів із накладанням випадкового нормального шуму, а також побудувати систему динамічного згладжування за допомогою цифрових фільтрів.

### Основні функціональні можливості програми:
1. **Моделювання сигналу:** Реалізовано математичну модель гармоніки вигляду $y(t) = A \cdot \sin(\omega t + \phi)$ за допомогою функції `harmonic_with_noise`.
2. **Керування параметрами:** За допомогою інтерактивних слайдерів (`matplotlib.widgets.Slider`) користувач може в реальному часі змінювати амплітуду, частоту, фазу сигналу, а також математичне очікування (середнє) та дисперсію накладеного шуму.
3. **Оптимізована генерація шуму (згідно з ТЗ):** Скрипт відстежує стан повзунків. Якщо змінюються параметри гармоніки, накладений шум залишається незмінним. Перегенерація випадкового масиву шуму відбувається *виключно* у разі коригування параметрів самого шуму.
4. **Цифрова фільтрація:** Зашумлений сигнал у реальному часі обробляється за допомогою фільтру Савицького-Голая (`scipy.signal.savgol_filter`). Додано окремий слайдер для динамічного підбору ширини вікна згладжування.
5. **Елементи інтерфейсу:** Програма містить інтерактивний чекбокс для швидкого приховування/відображення шуму, кнопку «Reset» для миттєвого відновлення початкових значень конфігурації та блок текстових інструкцій для користувача.
