## Опис завдання

Головна мета роботи — реалізувати інтерактивний програмний комплекс для моделювання гармонічних сигналів із накладанням випадкового нормального шуму, а також побудувати систему динамічного згладжування за допомогою цифрових фільтрів.

### Основні функціональні можливості програми:
* **Моделювання сигналу:** Реалізовано обов'язкову математичну модель гармоніки вигляду $y(t) = A \cdot \sin(\omega t + \phi)$ за допомогою функції `harmonic_with_noise`.
* **Керування параметрами:** За допомогою нативних інтерактивних слайдерів (`ipywidgets`) користувач може в реальному часі змінювати амплітуду, частоту, фазу сигналу, а також математичне очікування (середнє) та дисперсію накладеного шуму прямо всередині інтерфейсу VS Code.
* **Оптимізована генерація шуму (згідно з ТЗ):** Скрипт відстежує стан повзунків. Якщо змінюються параметри гармоніки, накладений шум залишається незмінним. Перегенерація випадкового масиву шуму відбувається *виключно* у разі коригування параметрів самого шуму.
* **Цифрова фільтрація:** Зашумлений сигнал у реальному часі обробляється за допомогою низькочастотного фільтра Баттерворта 3-го порядку (`scipy.signal.butter` та `filtfilt`). Додано слайдер **"Частота зрізу"** для динамічного підбору параметрів згладжування низьких частот.
* **Елементи інтерфейсу:** Програма містить інтерактивний чекбокс для швидкого приховування/відображення шуму, повноцінну кнопку **«Reset»** для миттєвого відновлення початкових значень конфігурації та вбудований блок текстових інструкцій для користувача.
