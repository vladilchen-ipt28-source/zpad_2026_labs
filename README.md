##  Опис завдання

Лабораторна робота присвячена первинному збору, аналізу, очищенню та статистичній обробці структурованих супутникових даних за допомогою інструментарію бібліотеки **Pandas**.

### Основні функціональні можливості програми:
* **Автоматизований скрейпінг даних:** Реалізовано модуль збору інформації, який через бібліотеку `requests` завантажує сирі супутникові дані індексів вегетації (VHI) для всіх адміністративних одиниць України безпосередньо з сервера NOAA.
* **Data Cleaning & Трансформація:** * Читання та об'єднання масиву створених CSV-файлів у єдиний DataFrame за допомогою `pd.read_csv`.
  * Гнучке оброблення зміщених заголовків, видалення системного сміття NOAA та некоректних рядків.
  * Виправлення критичного зміщення ідентифікаторів областей (приведення оригінального коду індексів NOAA до офіційного адміністративного поділу України).
* **Фільтрація та аналітичні вибірки (Pandas Queries):**
  * Реалізація процедури пошуку екстремумів (Min, Max) індексу VHI для заданої області за конкретний рік.
  * Пошук та виділення років із критичними посухами (VHI нижче встановленого порогу, що критично впливають на врожайність).
  * Фільтрація датасету за умовою помірної посухи (індекс VHI в межах від 20 до 35) з використанням логічних масок.
